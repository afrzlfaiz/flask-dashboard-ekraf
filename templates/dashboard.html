Tentang Proyek Dashboard Spasial Ekraf Kota Malang

Dashboard ini merupakan inisiatif visualisasi strategis oleh BAPPEDA Kota Malang untuk memetakan sebaran geografis pelaku ekonomi kreatif. Visualisasi dan spasial klastering ini mempermudah perumus kebijakan dalam menentukan zonasi stimulus ekonomi, pelatihan terarah, dan klasterisasi industri kreatif.

Panduan Penggunaan:
  1. Overview: KPI Utama, peta Leaflet.js, diagram, bagan subsektor, dan heatmap kepadatan.
  2. Clustering DBSCAN: Klaster berbasis kerapatan koordinat dengan parameter Epsilon dan Min Samples yang dapat disesuaikan.
  3. Tabel Data: Tabulasi lengkap dengan pencarian, sorting, pagination, dan ekspor Excel/CSV.
  4. Kelola Data: Form CRUD interaktif + impor berkas eksternal.
Catatan: Data disimpan di database SQLite dan diproses oleh Python backend (Flask). Semua perubahan memengaruhi peta, grafik, dan klastering secara langsung.
